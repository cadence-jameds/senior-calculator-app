手機上傳到 GitHub 的簡單方式：

1. 先把 senior-calculator-app.zip 下載到手機。
2. 解壓縮 ZIP。
3. 打開你的 GitHub Repository：
   cadence-jameds/senior-calculator-app
4. 建議使用 GitHub 網頁的 Add file → Upload files。
5. 上傳專案內所有檔案與資料夾。
   注意：不要把最外層 senior-calculator-app 資料夾再包一層上去。
   Repository 根目錄最後應該直接看到：
      app/
      .github/
      build.gradle
      settings.gradle
      gradle.properties
      README.md
6. Commit changes。
7. 點 Repository 上方 Actions。
8. 等待 Build Android APK 完成。
9. 進入成功的 workflow run，下載 Artifacts：
   senior-calculator-debug-apk
10. 解壓後安裝 app-debug.apk。

如果 GitHub 手機網頁不好一次上傳資料夾，可以改用 GitHub App 或手機瀏覽器「電腦版網站」。
