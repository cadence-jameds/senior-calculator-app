大字語音計算機

專為高齡使用者設計的 Android 大字離線計算機。

以 超大字、超大按鍵、簡單操作、高對比 為主要設計方向，適合手機及平板使用，並針對直向與橫向螢幕分別設計顯示比例。

目前版本

v1.0.0 正式版

主要功能

- 超大數字顯示
- 超大按鍵
- ＋、－、×、÷ 四則運算
- 四個運算按鍵使用不同顏色，方便辨識
- AC 全部清除
- 退格
- 小數點
- 等於
- 完整計算式顯示
- 計算結果以更大的字體顯示
- Android 原生繁體中文 TTS 語音
- 語音可自由開啟／關閉
- 語音預設關閉
- 按數字可朗讀
- 按運算符號可朗讀
- 按「＝」可朗讀答案
- 支援手機與平板
- 直向、橫向採用不同的介面比例
- 自動避開 Android 狀態列與底部導覽列
- 完全離線使用
- 不需要網路權限

長輩友善設計

本 App 主要以 70 歲以上高齡使用者為設計對象。

介面設計重點：

- 儘可能放大數字
- 儘可能放大操作按鍵
- 高對比配色
- 不加入不必要的功能
- 常用功能全部直接顯示
- 不使用複雜的多層選單
- 計算式與答案分開顯示
- 答案使用比計算式更大的字體
- 不同運算符號使用不同顏色
- 平板橫向使用時充分利用螢幕空間

完全離線

App 本身不需要網路即可使用。

"AndroidManifest.xml" 沒有宣告 INTERNET 權限。

因此四則運算等主要功能可以在完全沒有網路的環境下正常使用。

離線語音

語音功能使用 Android 原生 "TextToSpeech"。

若裝置已安裝「中文（台灣）」離線 TTS 語音資料，朗讀功能也可以完全離線使用。

若裝置沒有安裝中文離線語音資料，計算功能仍可正常使用。

為避免不需要語音的使用者受到干擾，App 安裝後語音預設為關閉，需要時可按「語音 開／關」自行切換。

下載與安裝

請從本專案的 GitHub Releases 下載最新正式版本。

目前正式版：

大字語音計算機 v1.0.0

APK：

"Senior-Calculator-v1.0.0.apk"

Android 安裝方式

1. 從 GitHub Releases 下載 "Senior-Calculator-v1.0.0.apk"
2. 開啟下載完成的 APK
3. 依照 Android 畫面指示進行安裝
4. 安裝完成後即可離線使用

«Android 第一次安裝自行下載的 APK 時，可能會要求允許瀏覽器或檔案管理員「安裝未知應用程式」。»

開發與編譯

本專案使用 GitHub Actions 自動編譯 Android APK。

每次更新程式後，可透過 GitHub Actions 建立正式 APK，再將確認完成的版本發布至 GitHub Releases。

一般使用者不需要使用 GitHub Actions，直接從 Releases 下載 APK 即可。
