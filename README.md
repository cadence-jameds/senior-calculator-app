# 大字語音計算機

專為高齡使用者設計的 Android 離線計算機。

**大字、大按鍵、操作簡單，手機與平板皆可使用。**

## 功能

- 超大數字與按鍵
- ＋、－、×、÷ 四則運算
- AC、退格、小數點、等於
- 計算式與答案分開顯示
- 直向、橫向自動調整介面
- 繁體中文語音朗讀
- 語音預設關閉，可自由開啟
- 完全離線使用
- 不需要網路權限

## 語音

使用 Android 原生 TextToSpeech。

裝置若已安裝「中文（台灣）」離線語音，即可在沒有網路的情況下朗讀數字與答案。

## 下載安裝

目前正式版：**v1.0.0**

請到 GitHub **Releases** 下載：

`Senior-Calculator-v1.0.0.apk`

下載後直接開啟 APK 安裝即可。

> 第一次安裝時，Android 可能會要求允許「安裝未知應用程式」。

## 技術資訊

- Android / Java
- minSdk 23
- targetSdk 35
- Android 原生 TextToSpeech
- 無 INTERNET 權限
